# Assignment 04

This assignment implements count-based Hindi N-gram language models using a tokenized Hindi text corpus.

## Files

- `Assignment_04.ipynb` — Main Jupyter Notebook
- `hindi_ngram_models/` — Saved language-model files generated by the notebook
- `../Assignment 01/hindi_texts_tokenized.parquet` — Input Hindi corpus

## Objectives

- Load and inspect a tokenized Hindi corpus.
- Split data into training, development, and test sets.
- Build unigram, bigram, trigram, and quadrigram models.
- Apply Laplace/Add-One smoothing.
- Evaluate models using perplexity.
- Save models as compressed pickle files.
- Upload the models to Hugging Face.

## Dataset

The notebook loads:

```text
../Assignment 01/hindi_texts_tokenized.parquet
```

The dataset is expected to contain:

- `sentence` — Original sentence text
- `words` — Tokenized word list

The notebook checks the number of sentences, columns, and missing values.

## Data Splitting

A fixed random seed is used:

```text
Seed: 42
Development set: 1,000 sentences
Test set: 1,000 sentences
Training set: All remaining sentences
```

The vocabulary is built only from the training data to avoid data leakage.

## Special Tokens

The following boundary and unknown-word tokens are used:

```text
<s>     Sentence start
</s>    Sentence end
<UNK>   Unknown word
```

Unknown words not found in the training vocabulary are replaced with `<UNK>`.

## Language Models

The notebook builds four count-based models.

### Unigram

Estimates the probability of an individual word:

```text
P(w)
```

### Bigram

Estimates the probability of a word given the previous word:

```text
P(w₂ | w₁)
```

### Trigram

Estimates the probability of a word given the previous two words:

```text
P(w₃ | w₁, w₂)
```

### Quadrigram

Estimates the probability of a word given the previous three words:

```text
P(w₄ | w₁, w₂, w₃)
```

## Smoothing

Laplace/Add-One smoothing is applied to all probability calculations.

For example, the bigram probability is:

```text
P(w₂ | w₁) = (C(w₁, w₂) + 1) / (C(w₁) + V)
```

where:

- `C` is the observed count.
- `V` is the vocabulary size.

Smoothing prevents unseen n-grams from receiving zero probability.

## Evaluation

Each model is evaluated on the development and test sets using perplexity.

Lower perplexity generally indicates better predictive performance.

The notebook produces:

- Unigram perplexity
- Bigram perplexity
- Trigram perplexity
- Quadrigram perplexity

A comparison table and bar graph are generated for the test-set results.
